## 更新源

此包首次运行生成的 `data/update.json` 中 `manifestUrl` 为空，**上传 GitHub 不会自动让已有程序发现更新**。

可在应用数据目录的 `update.json` 中配置：

```json
{
  "manifestUrl": "https://raw.githubusercontent.com/Wangyibo0703/zhihuishu-study-assistant/main/version.json"
}
```

也支持环境变量 `ZHS_UPDATE_URL`。本次 `version.json` 保持 `version` 与 `minSupported` 都为 `0.1.0`，不会要求此版本升级。若未配置或网络不可达，更新提示可能不可用；已有缓存会影响版本判断。

`sha256` 用于发布记录和人工核对；当前客户端不会因此自动验证下载文件或安装更新。
