# 使用说明

## 首次运行

1. 从本仓库 Releases 下载 Windows x64 压缩包，完整解压到可写文件夹。
2. 双击 `智慧树学习助手-测试版v0.1.exe`，阅读并确认使用声明。
3. 在「刷课」页输入课程名；留空时按课程队列处理。点击「开始刷课」。
4. 在弹出的独立 Edge 窗口内登录；出现验证码时自行完成验证。
5. 查看桌面端显示的当前课程、视频、进度和日志；需要结束时点击「停止刷课」。

专用浏览器配置与日常浏览器配置分开保存。首次登录、会话过期或重置配置后需要重新登录。

## 设置

「设置」页支持修改浏览器打开网址、切章阈值、刷新间隔、卡顿判定、验证码等待、弹题作答延迟、换片等待，以及从头播放、异常停止、响铃和提醒置顶等开关。保存后在下一次开始任务时生效。

默认切章阈值为 81%；这是工具配置值，不能代替平台对学习完成的认定。随机弹题处理不提供正确率保证。

## 数据位置

桌面主进程的打包版目录：`%APPDATA%\智慧树学习助手\data`。内核数据目录存在初始化顺序问题，实际浏览器配置与日志位置可能不同；请同时检查启动目录及其上一级的 `data/`、`logs/`、`shots/`。维护者定位信息见 [开发说明](开发说明.md#已知目录初始化问题)。

| 位置                                    | 内容                     |
| --------------------------------------- | ------------------------ |
| `auto-study/config.json`                | 任务参数                 |
| `auto-study/edge-profile/`              | 专用浏览器配置与登录资料 |
| `auto-study/state/`                     | 运行状态、会话与断点     |
| `auto-study/logs/`、`auto-study/shots/` | 内核运行日志与截图       |
| `logs/`                                 | 桌面应用日志             |
| `update.json`                           | 更新源配置               |

请勿将这些目录作为软件附件上传。重置浏览器配置会清除专用配置中的登录状态，操作前请结束任务。

## 常见问题

- 无法打开浏览器：确认已安装 Microsoft Edge；非标准安装路径可由维护者检查 `EDGE_PATH` 配置。
- 提示等待登录：在弹出的专用 Edge 窗口中登录，之后等待程序识别。
- 出现验证码：人工完成后等待继续，不会自动绕过。
- 平台异常或任务停止：阅读日志中的原因，先处理平台提示；不要连续重试。
- 下载后打不开：确认完整解压且资源文件齐全，记录系统提示后提交 Issue。
- 没有更新提示：此包默认没有配置更新源，参阅维护与发布文档。

## 已知限制

当前为 Windows x64 测试版；不同课程和站点改版的兼容性尚需验证。章节测试未接入默认桌面流程，验证码与倍速需要人工操作。不要同时打开多个课程播放页；平台是否完成始终以官方页面为准。
