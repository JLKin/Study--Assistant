四条铁律

            
    
              
  1. 
                平台只认真实观看时长。脚本内部会强制从头播，进度条往前拖不计数，还会被判异常。
              
    2. 
              
  2. 
                倍速只能你手点。视频右下角 X 1.0 → X 1.5，脚本一碰速度 1 秒内就会弹「检测到异常脚本」。
              
    3. 
              
  3. 
                人机验证要人工点掉。出现「请点击正向的小写 t」这类验证码时去 Edge 窗口点一下，解完自动继续。
              
    4. 
              
  4. 
                同一时间只开一个播放页。多个播放页互相抢焦点会让站点把视频暂停。
              
    5. 
            

          


          

            

              
它做了什么

              
    
                
  • 视频播到 81% 自动切下一个，完成标记由平台记账
    • 
                
  • 中途弹题随机作答、关掉弹层后自动续播
    • 
                
  • 「学前必读 / 课程提醒」等弹窗自动关闭
    • 
                
  • 播放停滞、丢页自动自愈，断点续跑
    • 
                
  • 共享课 5 门 + 智慧课程「人工智能引论」，两套播放页都支持
    • 
              

            

            

              
它不做什么

              
    
                
  • 不改倍速、不拖动进度条（会被判异常脚本）
    • 
                
  • 不自动提交章节测试（后续版本）
    • 
                
  • 不读取账号密码，登录只在 Edge 里由你本人完成
    •
